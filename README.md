# 🎬 MithuVideoMaker

> মালিক: **মিথুন** · লোকাল, ফ্রি, আনলিমিটেড · কোনো API বা সাবস্ক্রিপশন লাগে না

ছবির একটা ফোল্ডার দিলে **অটোমেটিক ভিডিও** বানিয়ে দেয় — Ken Burns জুম ইফেক্ট,
ক্রসফেড ট্রানজিশন, টাইটেল, ব্যাকগ্রাউন্ড মিউজিক সহ।

## 📁 ফোল্ডার স্ট্রাকচার

```
MithuVideoMaker/
├── make_video.py          ← মূল স্ক্রিপ্ট
├── assets/
│   ├── images/            ← এখানে তোমার ছবি নামাও (01, 02, 03... নামে)
│   ├── music/             ← ব্যাকগ্রাউন্ড মিউজিক (mp3/m4a)
│   └── output/            ← তৈরি ভিডিও এখানে সেভ হয়
└── README.md              ← এই ফাইল
```

## 🚀 কীভাবে চালাবে

### সবচেয়ে সহজ (Reels/Shorts — উল্লম্ব):
```bash
cd ~/Documents/Default\ Project/MithuVideoMaker
python3 make_video.py assets/images --vertical
```

### মিউজিক + টাইটেল সহ (ফ্যান্সি ট্রানজিশন):
```bash
python3 make_video.py assets/images \
  --music assets/music/demo_pad.m4a \
  --title "আমার ভিডিও" \
  --vertical --fancy --seconds 4.5 \
  --out my_reels.mp4
```

### YouTube মোড (অনুভূমিক 16:9):
```bash
python3 make_video.py assets/images --out youtube_video.mp4
```

## ⚙️ সব অপশন

| অপশন | কাজ |
|---|---|
| `--vertical` | 1080×1920 (Reels / Shorts / TikTok) |
| (না দিলে) | 1920×1080 (YouTube 16:9) |
| `--music ফাইল` | ব্যাকগ্রাউন্ড মিউজিক (অটো ট্রিম + fade out) |
| `--title "টেক্সট"` | প্রথম ৪ সেকেন্ডে বড় টাইটেল |
| `--fancy` | ৮ ধরনের ট্রানজিশন মিক্স (fade, circleopen, smoothleft...) |
| `--seconds N` | প্রতি ছবি N সেকেন্ড (ডিফল্ট ৫) |
| `--out নাম.mp4` | আউটপুট ফাইলের নাম |
| `--font ফাইল.ttf` | কাস্টম ফন্ট |

## 🖼️ ছবি নামানোর নিয়ম

1. ছবিগুলো `assets/images/` ফোল্ডারে ফেলো
2. **নাম অনুযায়ী সিরিয়াল** হবে: `01.jpg`, `02.jpg`, `03.jpg`...
3. jpg, png, webp — যেকোনো সাইজ চলবে (স্ক্রিপ্ট নিজেই ফিট করে)

## 🌐 ওয়েবসাইট মোড — MithuStudio (সব এক জায়গায়)

দুটো স্টুডিও একসাথে — একটা লিংক, একটা সার্ভার:

```bash
cd ~/Documents/Default\ Project/MithuVideoMaker
python3 app/server.py
```

তারপর ব্রাউজারে খোলো: **http://127.0.0.1:8765**

| পেজ | কী করে |
|---|---|
| `/` | হোম — তিনটা স্টুডিওর দরজা |
| `/script` | **স্ক্রিপ্ট → ভিডিও** (লিখলেই অটো ভিডিও + ভয়েস) |
| `/studio` | ছবি → ভিডিও (drag-drop, মিউজিক, লুপ) |
| `/animation` | কীফ্রেম অ্যানিমেশন স্টুডিও |

সবচেয়ে সহজ: Finder-এ প্রজেক্ট ফোল্ডারের **`start.command`** ফাইলটা
**ডাবল-ক্লিক** করো — পুরোনো সার্ভার বন্ধ করে নতুনটা চালু করে ব্রাউজার খুলে দেবে।

| 🎬 দৃশ্য এডিটর | প্রতি লাইনের ক্যারেক্টার / এক্সপ্রেশন / অ্যাকশন / দৃশ্য / সময় মাউস দিয়ে বদলানো যায় — "সব অটোতে ফেরাও" বাটনও আছে |

**অ্যানিমেশন কোর্সের স্কিলগুলোও এখন অটো** (নিচের টেবিল) — আলাদা করে কিছু করতে হয় না,
স্ক্রিপ্ট দেখে সাইট নিজেই ঠিক করে কোন ক্যারেক্টার, কোন এক্সপ্রেশন, কোন অ্যাকশন লাগবে।

| কোর্সের স্কিল | সাইটে কীভাবে কাজ করে |
|---|---|
| 🧒 ক্যারেক্টার ডিজাইন | ৬৪টা রেডি ক্যারেক্টার — ১৭ মানুষ, ৪৩ প্রাণী (বাঘ-হাতি-জিরাফ-হাঙর-মৌমাছিসহ), ৪ কল্পনার — প্রতিটার বাস্তব-আপেক্ষিক মাপ (হাতি বিশাল, ইঁদুর ছোট); রং/কান/লেজ/টুপি বদলে আরো বানানো যায় |
| 🦴 রিগিং | প্রতিটা ক্যারেক্টারের হাড়/জোড়া — কাঁধ, কোমর, হাঁটু, কনুই নিজে থেকে বাঁকে |
| 👄 লিপ সিঙ্ক | ভয়েসের অডিও খুঁজে মুখের ওঠানামা — কথা বলার সময় ঠোঁট সত্যিই নড়ে |
| 🚶 ওয়াক / রান সাইকেল | "হাঁটে", "দৌড়ায়" লিখলেই পা-হাত পালা করে নড়ে শরীর ওঠে-নামে — **মাটি বেয়ে সত্যিই স্ক্রিন পেরিয়ে হেঁটে যায়** |
| 🤸 জাম্প | স্কোয়াশ আর স্ট্রেচ সহ লাফ (উঠে আবার পড়ে) |
| 💃 নাচ ও ঘুম | "নাচছে", "গান", "ঘুম", "শোয়া" লিখলেই নাচে (হাত-কোমর ঢংয়ে) বা ঘুমায় (চোখ বন্ধ, "জজজ" ভেসে ওঠে) |
| 🙂 এক্সপ্রেশন | খুশি, দুঃখ, কান্না (চোখের জল), রাগ, ভয় (ঘাম), অবাক (!), ভাবছে (?) |
| 💬 সংলাপ | `রাজু: কেমন আছো?` লিখলেই কে বলছে বুঝে ও এক পাশে বলে, আগে যারা বলেছে তারা অন্য পাশে ছোট হয়ে শোনে — এক ফ্রেমে ৩ ক্যারেক্টার পর্যন্ত |
| ⭐ ক্রিয়েটরের ক্যারেক্টারটা বলে | ক্রিয়েটরে বানানো ক্যারেক্টারের নাম সংলাপে লিখলেই **ওই ক্যারেক্টারই** সেই কথা বলে অভিনয় করে |
| 🧍 সবাই মাটিতে | কোনো ক্যারেক্টারই আর হাওয়ায় ভাসে না — দৃশ্য বা সংলাপ থাকলে সবাই মাটিতে দাঁড়ায় |
| 👄 লিপ সিঙ্ক + ভাওয়েল | কথা বলার সময় ঠোঁট আ-ই-উ-এ-ও আকার নেয় — প্রতি দৃশ্যে আলাদা আঙুল ছাপ |
| 🎥 ক্যামেরা + প্যারালাক্স | ধীরে জুম ইন/আউট, ডানে-বাঁয়ে প্যান — পেছনের স্তর আলাদা গতিতে নড়ে |
| 🎭 মাস্ক / মরফ ট্রানজিশন | দৃশ্য বদলে বৃত্ত, ব্লব (শেপ মরফ), বার, ওয়াইপ দিয়ে খুলে আসে |
| 🌄 লুপ ব্যাকগ্রাউন্ড | মেঘ, পাহাড়, জোনাকি — সিমলেসভাবে ঘুরতে থাকে |
| 🎞️ ফ্রেম-বাই-ফ্রেম এক্সপোর্ট | প্রতিটা ফ্রেম ffmpeg-এ যায় → হুবহু ৩০ fps, ফ্রেম মিস হয় না |

### 🎵 Step 3 — শব্দের জাদু
| সুবিধা | বিবরণ |
|---|---|
| 🎭 অटো ভয়েস | সাইট ক্যারেক্টার দেখে গলা ঠিক করে — শিশু (৩০% চিকন), মেয়ে (১০% চিকন), পুরুষ (মোটা), বিড়াল-খরগোশ-পাখি (সবার চিকন), হাতি-বাঘ-সিংহ (ভারী), রোবট (ট্রেমোলো), ভূত (গভীর-ট্রেমোলো) — নিজের বানানো ক্যারেক্টারও নিজের গলায় কথা বলে |
| 🌿 প্রাকৃতিক শব্দ (SFX) | দৃশ্য আর লেখা দেখে নিজে মিক্স করে: বন/মাঠ=পাখি ডাকা, রাত=ঝিঝঝিঝ পোকা, সমুদ্র=ঢেউ, বরফ/মরুভূমি=বাতাস, শহর=গুঞ্জ, মহাকাশ=প্যাড, হাঁটা/দৌড়=পায়ের শব্দ, বৃষ্টি=বৃষ্টির শব্দ, জাদু/জোনাকি=ঝিকিমিকি (সব কপিরাইট-ফ্রি — ffmpeg দিয়েই সিন্থেসাইজ) |
| 🎶 অটো মিউজিক | মিউজিক "অটো" দিলে গল্প চেখে সিদ্ধান্ত — গল্পটা বেশি দুঃখের/ভয়ের হলে কাম, নাহলে ব্রাইট |
| 🔇 SFX বন্ধ | "🌿 প্রাকৃতিক শব্দ" চেকবক্স ছাড়লে SFX বন্ধ থাকবে |
| 📄 সাবটাইটেল (.srt) | "📄 সাবটাইটেল নামাও" বাটন — সময়-মিলিত .srt ফাইল নামবে, YouTube-এ দিলেই ক্যাপশন চলবে |
| 📌 সব শব্দ একসাথে | মিউজিক + SFX + ভয়েস তিনটা একসাথে মিক্স হয় — ভয়েস সবার ওপরে, SFX পেছনে, মিউজিক সবার নিচে |

> ভয়েসের জন্য macOS-এর `say` ব্যবহার হয় — ইন্টারনেট বা কোনো ক্লাউড লাগে না।
> রেন্ডারও পুরোটা তোমার কম্পিউটারে — কোনো সার্ভার, API বা ওয়াটারমার্ক নেই।

### 🎬 Step 4 — প্রো সিনেমা জিনিস
| সুবিধা | বিবরণ |
|---|---|
| 🖐️ স্ক্রিপ্ট-নির্দেশ | স্ক্রিপ্টে লেখলেই সাইট বোঝে — `ডানে`/`বাঁয়ে`/`মাঝখানে` হলে ক্যারেক্টার সেই পাশে দাঁড়ায়; `কাছে চলে আসে`/`জুম` হলে ক্যামেরা কাছে আসে, `দূরে যায়` হলে দূরে সরে |

| ➡️ স্লাইড | এক পাশ থেকে পুরো দৃশ্য সরে এসে ঢেকে দেয় |

| 🕊️ নতুন অ্যাকশন ৪টা | তাকানো (👀 মাথা এদিক-ওদিক), তালি (👏 হাত মেলায়), মাথা নাড়া (🙂 হ্যাঁ-ইশারা), উড়া (🕊️ ডানা ঝাপটিয়ে ভাসে) |

| 😍 আরো ৩ এক্সপ্রেশন | ভালোবাসা (হার্ট-চোখ ❤️ + ভাসমান হার্ট), ঘুমঘুম (💤 z z z), গর্বিত (✨ ঝিলিক) — চোখ, মুখ, বাবল সবই বদলায় |

| 🖱️ টেনে স্ক্রাব | প্রোগ্রেস-বারে ক্লিক করো বা **মাউস চেপে টেনে** যেকোনো সময়ে যাও — ভিডিও থেমে সেই মুহূর্ত দেখায় |
| ▶ দৃশ্য-প্রিভিউ | প্রতিটি দৃশ্যের পাশে ▶ — শুধু সেই দৃশ্যটাই চলে, শেষ হলে নিজেই থামে |
| 🟢 চলমান-দৃশ্য আভা | যে দৃশ্যটা এখন চলছে সেটা দৃশ্য-এডিটরে **সবুজ আভায়** জ্বলে ওঠে; পাশে `m:ss` ব্যাজে দেখা যায় ভিডিওতে কখন শুরু |
| 🔊 কথা শুনি | ভিডিও না বানিয়ে শুধু কণ্ঠগুলো একের পর এক শুনে দেখো — 🔴 থামাও চাপলে থেমে যায় |
| 📖 গল্প-বোঝা | স্ক্রিপ্ট পুরোটা আগে **পড়ে ফেলে** — "রাজু: কথা" সংলাপের নাম, আত্মীয়তা-শব্দ (দাদু/দাদি/মা/খোকা), "এক ছিল ___" গল্প-সুর আর ২+ বার উল্লেখ হওয়া নাম থেকে **যারা যারা গল্পে আছে তাদের নিজেই বানায়**: "লাল শিয়াল" বললে লাল প্রাণী-ক্যারেক্টার, "নীল" বললে নীল জামা, "দাদু" বললে দাড়ি-চশমা, "খোকা" বললে ছোট বাচ্চা — তারপর প্রতিটা লাইনে **সেই ক্যারেক্টারই** অভিনয় করে। বানানোগুলো দৃশ্য-এডিটরের ক্যারেক্টর-লিস্টে "📖 গল্পের ক্যারেক্টার" হিসেবে দেখা যায় (সেভ হয় না — প্রতিবার গল্প থেকেই নতুন) |

## ❗ টিপস

- **বাংলা টাইটেল**: ffmpeg-এর text renderer বাংলা যুক্তাক্ষর ভুল দেখাতে পারে।
  বাংলা টাইটেল দরকার হলে আমাকে বলো — আমি PNG বানিয়ে ওভারলে করে দেবো।
- **রক্সি ছবি বড়?** চিন্তা নেই — স্ক্রিপ্ট অটো-লো-ডাউন করে।
- **আনলিমিটেড**: যতবার খুশি চালাও — কোনো ক্রেডিট/কোটা নেই ✨
- **রেন্ডার কত সময় নেয়?** ২৩ সেকেন্ডের ভিডিও (৬ দৃশ্য, ভয়েস+মিউজিক) এই ম্যাকে
  ~৩০–৪০ সেকেন্ডে তৈরি হয়। ভিডিও ঠিক ৩০ fps-এ আসে, ফ্রেম মিস হয় না — তাই ট্যাব
  অন্য জায়গায় নিয়ে গেলেও এক্সপোর্ট চলতে থাকে।
- নতুন এফেক্ট চাইলে (slow motion, ভয়েসওভার, স্প্লিট-স্ক্রিন...) আমাকে বলো —
  আমি স্ক্রিপ্ট আপগ্রেড করে দেবো।
